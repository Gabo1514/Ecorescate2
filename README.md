# Operación EcoRescate
> Videojuego educativo interactivo sobre el cuidado y preservación del medio ambiente en la provincia de Ica, Perú. Diseñado para estudiantes de educación primaria (6 a 12 años).

---

## ¿Cómo Jugar Online Gratis en GitHub Pages?

1. Sube este repositorio a tu cuenta de **GitHub**.
2. En tu repositorio, ve a **Settings** (Configuración) > **Pages** (en el menú lateral izquierdo).
3. En **Branch**, selecciona `main` (o `master`) y la carpeta `/ (root)`.
4. Haz clic en **Save** (Guardar).
5. En 1 o 2 minutos, GitHub te dará un enlace como:
   `https://tu-usuario.github.io/tu-repositorio/`

---

## ¿Cómo Ejecutar Localmente?

El juego está desarrollado en **HTML5 Canvas, Vanilla JavaScript y Web Audio API procedural**, por lo que **no requiere instalar Node.js, librerías externas ni servidores complejos**:

* **Opción Directa:** Abre el archivo `index.html` o `web/index.html` directamente con tu navegador (Chrome, Edge, Firefox, Safari).
* **Con Servidor Local (Recomendado):**
  ```bash
  python -m http.server 8080 --directory web
  ```
  Luego abre en tu navegador: `http://localhost:8080/`

## Los 4 Minijuegos Educativos (40 Niveles)

1. **Limpieza Monstruosa (La Plaza de Armas de Ica):**
   Clasifica botellas plásticas, cajas de cartón y latas de metal en sus respectivos tachos de reciclaje. Esquiva el lodo tóxico contaminante.
2. **Guardián del Agua (Lavaderos Escolares):**
   Cierra caños desatendidos, goteos y grifos abiertos durante el cepillado de dientes para ahorrar miles de litros de agua en la región desértica de Ica.
3. **Apaga y Ahorra (Aulas y Pabellones):**
   Apaga focos y equipos en aulas desocupadas y desconecta cargadores solos para combatir el consumo fantasma de energía eléctrica.
4. **Sembradores del Verde (El Biohuerto Escolar):**
   Siembra semillas, aplica riego inteligente (únicamente cuando la tierra esté seca para no asfixiar las raíces) y cosecha hortalizas y flores frescas.

## Características y Gamificación

* **Tienda de Personalización:** Desbloquea y equipa 8 accesorios (gorras, lentes, audífonos, sombrero iqueño, capa de héroe, corona de laurel, visera) y 6 colores de polo escolar con tus EcoMonedas.
* **14 Medallas Coleccionables:** Reconocimientos al ahorro de agua, velocidad de reciclaje, siembra óptima y conocimiento ecológico.
* **Desafío del Saber:** Preguntas pedagógicas contextualizadas sobre la geografía, fauna (como el huerequeque) y recursos hídricos de Ica.
* **Modo Eco-Frenesí y Eco-Burbujas:** Multiplicadores dobles de puntos, burbujas de bonificación y retroalimentación visual dinámica.
* **Exportación de Datos en CSV:** Permite a los docentes descargar el progreso y métricas de impacto ambiental de cada estudiante.
